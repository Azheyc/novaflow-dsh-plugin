## 当前行为基线

- NovaFlow 浏览器 PKCE 授权；设备凭据由 DSH Credentials 服务保存。
- 模型交给官方“设置 → 模型”管理；受管配置首次迁移采用 OpenAI Responses、文字和图片输入及可选思考档位，后续保留用户原生编辑。
- 登录成功或恢复登录后显示推荐插件提醒；**用户在弹窗点击“确认并开始安装”才启动官方安装器**。关闭、读取状态、刷新和 Agent 请求重试均不会开始安装。
- 图片默认模型为 `gpt-image-2.6`；视频必须由用户明确指定模型。长任务查询原作业，不自动重复提交。
- 不依赖外部 Magpie 设置；同名 MCP 客户端冲突仍须核对有效预设，详见故障排查。

## 文档维护规则

1. 功能与配置的依据是当前源码和运行时 Inspect；DSH 升级后重新核对接口。
2. 行为变更同步更新对应手册与使用说明。发布版本同步更新清单和 release 常量，步骤见测试与发布。
3. 验证记录区分隔离测试、实际资源检查、浏览器操作、Windows 实机和真实平台请求；未执行的项目明确标注。
4. 历史验证保留原结论与日期；新行为以当前版本章节为准。2.3 的登录后直接安装已被 2.4 的确认门槛取代。
5. 文档、示例和诊断材料只记录凭据名称及脱敏摘要，不复制设备令牌、连接密钥或网页登录会话。

文档整理阶段仅修改说明，未重打包；随后 GitHub 首次发布重新生成包含这些文档的2.4.0安装包。公开仓库和下载入口见[项目首页](../README.md)，验证区分发布前测试与此前运行实例证据，详见[验证记录](../VERIFICATION.md)。
