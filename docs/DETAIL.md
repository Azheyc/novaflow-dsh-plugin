# NovaFlow 账户与原生模型配置

使用浏览器跳转到 NovaFlow 登录并确认授权，连接自动保存到 DeepSeek Harness 官方“设置 → 模型”。在原生页面获取、添加、编辑和删除模型；每个模型的高级设置可配置思考档位，再在对话模型选择器选择实际思考深度。

模型显示原始名称，不追加分组后缀。分组由提供商归属区分。后台同步保留原生模型编辑与删除操作。

仅适配 DSH 0.2.2-rc.2。按用户要求，受管模型统一采用OpenAI Responses，开启图片输入与off/low/medium/high/xhigh/max思考档位；实际后端能力仍以平台为准。平台设备接口暂不提供余额，账户页链接到平台查看。

内置magpie-image MCP，无需在Magpie配置模型。图片默认使用NovaFlow gpt-image-2.6；视频必须由用户明确指定模型，未指定时先列可用模型供选择。长任务返回ID，通过结果工具查询，不自动重复提交。

登录后弹窗提醒，用户点击“确认并开始安装”后才通过DSH官方安装器、registry.npmmirror.com镜像初始化插件市场及dsh-ops、dsh-free-search、归档管理和回退插件。已安装跳过、禁用选择保留；显示失败与重启提示。Windows优先检测DSH内置pnpm，缺失时提供官方桌面版修复指引，不修改系统PATH或自动批准脚本。

退出清登录凭据并撤销当前设备，保留原生提供商和模型配置；本机连接地址由插件维护。停用整个插件包可恢复官方账户界面。
